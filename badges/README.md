# Brainrot Plaza badges

One image per achievement (512×512, Roblox crops it to a circle). `_preview.png` shows them all.

## How to make a badge

1. Go to **create.roblox.com** → **Creations** → click **Brainrot Plaza** → **Associated Items** → **Badges** → **Create a Badge**.
2. Upload the image from this folder, and copy the **Name** and **Description** from the table below.
3. After it's created, copy the badge's **ID** (the number in its link).
4. In `SocialAndRewardsServer`, find that achievement's line and change `badge = 0` to `badge = <the ID>`.

Players who already have the achievement get the badge automatically the next time they join.
Roblox lets you create a few badges free each day, so start with the ones players will earn most (the top of the list).
